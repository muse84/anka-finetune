# anka-finetune — 单角色中文对话模型的 LoRA 微调实践

> 个人学习项目：基于开源大语言模型做单角色角色扮演（RP）微调的完整数据管线与训练工程记录。
> 非商用、粉丝向（fan-made）、仅本地部署自用。

## 项目性质声明

- **个人学习项目**：目的是实践大模型监督微调（SFT）的完整工程流程——数据构建、清洗审计、切分、训练、评估。
- **非商用**：不提供任何公开服务，不涉及任何商业用途。
- **角色来源**：基于某手机游戏角色的粉丝向二次创作。角色相关语料由本人自行整理编写，仓库**不上传任何游戏原始素材**（音频/立绘/官方文本）。
- **底模**：Qwen3 9B 系列开源模型（Apache 2.0 许可），仅做 LoRA 适配器训练。

## 技术方案

| 环节 | 方案 |
|---|---|
| 训练框架 | ms-swift（LoRA SFT） |
| 微调方式 | LoRA rank 32 / alpha 64 / dropout 0.05 / all-linear |
| 数据规模 | 自建单角色中文对话语料 1825 条 → 训练集 2339 行（含少量身份类过采样） |
| 序列控制 | max_length 3072，group_by_length 按 length 分桶省显存 |
| 硬件 | 单卡 MI300X（191GB），4 epochs ≈ 588 步 ≈ 3.5~3.8 小时 |
| 评估 | 保留独立 val/test（各 31 条）+ 固定压测题集人工评估 |

## 数据说明（重要）

完整训练语料为**本地私有数据，本仓库不上传**，原因：

1. 语料中包含粉丝向创作内容，不适合无条件公开分发；
2. 避免任何游戏知识产权内容的二次传播。

仓库内提供：

- `data/sample_redacted.jsonl` — **8 条脱敏样例**，展示数据格式与设计思路（ShareGPT 结构：system 记忆卡 + user/assistant 多轮）；
- `docs/pipeline.md` — 完整数据管线说明（构建 → 审计 → 切分 → 格式转换 → 打包自检）；
- `scripts/` — 管线核心脚本（构建、切分、校验、格式转换、打包自检）。

## 内容安全设计

数据集在构建时显式包含以下安全类样本（见样例文件）：

- **拒绝类**：损害他人/违规请求一律角色内拒绝（`peer_bound` 类，126 条）；
- **身份认知**：角色对自身虚拟属性的平稳、诚实认知，不冒充人类；
- **防谄媚（anti-sycophancy）**：专门构造指责/迁怒/嘲讽类用户输入及对应的"有边界、不无底线顺从"的回复样本；
- **格式约束**：回复简洁口语化，禁止长篇 AI 腔输出。
